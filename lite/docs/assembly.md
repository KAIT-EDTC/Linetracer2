## 1. 基板の記号の見かた

| 記号（基板の白い印刷） | 場所 | 意味 |
|------|------|------|
| **▲まえ** | 左前 | ロボットの前。センサーがある側 |
| **丸い数字 ①〜⑩** | 部品のそば | **つくる順番**（§2） |
| **ちゃ / だいだい / あか** | 抵抗の上 | 抵抗の **3 本目の帯の色**。どの抵抗も「ちゃ・くろ・**？**・きん」で、3 本目だけがちがう。きん色の帯と反対の端から数える。ちゃ = 100 Ω、だいだい = 10 kΩ、あか = 1 kΩ |
| 半円の形 | トランジスタ Q1 | 部品の形と同じ向きに差す（平らな面がうしろ） |
| **LED の絵**（長い足に ＋） | LED のそば | LED は **長い足が ＋**。パッドの横の **＋** の穴に長い足 |
| 丸の半分が**しましま** | 大きいコンデンサ C1・C2 | コンデンサの **白い帯（−）をしましまの側**に。長い足が ＋ |
| 太い線 | ダイオード D1 | ダイオードの **白い帯を太い線の側**に |
| **1** | モータードライバーの右はし | モジュールの **1 番ピンを右**に |
| **USB** | マイコンの右はし | マイコンの **USB を右の端**に（基板から少し出る） |
| **＋ −**、RED / BLK | でんち（J1） | 赤い線が ＋ |
| **＋ −** | モーターのパッド | モーターの ＋ 端子（赤い印があればその端子）を ＋ に。逆でもソフトの設定で直せる |
| **S1 S2 S3** | 前 | センサーの番号（ひだり・まんなか・みぎ） |
| **スキッド** | 前のまんなかの穴 | スキッドを差す穴 |
| 裏の **センサー**、四角の形と ● | 裏の前 | センサーは **裏から** 差す。四角のかけた角（●の側）にセンサーのかけた角 |

## 2. はんだ付けの順番（基板の ①〜⑩）

背の低い部品から順に付ける。どの部品も「差す → 裏返して はんだ → 足を切る」。

| 番号 | 部品 | 数 | 向き・気をつけること |
|------|------|----|----------------|
| ① | **抵抗** | 8 | 抵抗の上の色の名前と、抵抗の 3 本目の帯の色を合わせる（ちゃ ×3、だいだい ×3、あか ×2）。向きはどちらでもよい。足を 10 mm 間隔に曲げる |
| ② | **ダイオード** D1（1N5819） | 1 | 白い帯を、印刷の太い線の側に |
| ③ | **小さいコンデンサ** C3・C4（0.1 µF） | 2 | 向きはどちらでもよい |
| ④ | **トランジスタ** Q1、**ボタン**、**LED** | 各 1 | Q1 は半円の形に合わせる（平らな面がうしろ）。ボタンはパチッと奥まで。LED は長い足を ＋ に |
| ⑤ | **でんちのコネクタ** J1 | 1 | **先に電池ボックスのプラグを差して、赤い線が ＋（RED）に来る向きで置いてから**はんだ付け（逆だと壊れる） |
| ⑥ | **大きいコンデンサ** C1・C2（470 µF） | 2 | 白い帯（−）をしましまの側に。長い足が ＋ |
| ⑦ | **モータードライバー**（AE-TC78H653FTG） | 1 | 先生がモジュールに付属のピンヘッダを付けておく。**1 番ピンを右**に（印刷の 1） |
| ⑧ | **マイコン** XIAO ESP32C6 | 1 | §3。**やり直しができないので先生と一緒に** |
| ⑨ | **センサー** LBR-127HLD | 3 | §4。**裏から** |
| ⑩ | **モーターの線** | 4 本 | 標準版と同じ（`../../docs/06_assembly.md`）。左のモーターは M1、右は M2 |

## 3. マイコン（XIAO）を基板にじかにはんだ付けする

> **やり直しがきかない**。はじめての子は先生がとなりで見る。低学年なら先生が先に付けておく。

1. MicroPython が入っていて動くことを確かめておく（§0）。
2. XIAO を**部品面を上**にして、**USB を右**に（印刷の「USB」の側。USB の口が基板の右の端から少し出る）。14 個の半円の穴を、基板の 14 個の細長いパッドの真ん中に合わせる。
3. 指（または洗濯ばさみ）で押さえて、**対角の 2 か所（1 番と 8 番）だけ先に**はんだ付け。浮いていないか横から見る。
4. 残りを 1 か所ずつ: こて先を**基板のパッド（XIAO の外にはみ出した所）と半円の穴の両方**に当てて 2 秒 → はんだを当てる → 半円の穴にはんだが吸い上がればよい。
5. **となりのピンとのブリッジ**をルーペで見る。特に **5V と GND、GND と 3V3**（USB に近い列）はつながると電源がショートする。
6. XIAO の裏の小さなパッドには**はんだを付けない**（基板側は銅が無いので触れても大丈夫）。

## 4. センサー（LBR-127HLD）を裏に付ける

1. センサーを**基板の裏から**差す。裏の四角の印の**かけた角（● の側）に、センサーのかけた角**を合わせる（長い足 2 本がアノードとエミッタ）。
2. 本体を基板の裏に**すきまなく押し付けて**、表ではんだ付けし、足を切る。浮くとセンサーの高さが変わる。
3. 3 個とも同じ向き・同じ高さか横から見る。

## 5. 最初の確認（テスター）

1. 電池を入れずに、J1 の ＋ と −、**XIAO の 5V と GND、3V3 と GND** がショートしていないか。
2. XIAO の 14 本のうち、となりどうしがつながっていないか。
3. USB をつなぎ、Thonny で `../firmware/micropython/examples/01_led_blink.py` → 赤 LED と XIAO の黄 LED が交互に光れば OK。

## 6. 機械の組み立て（標準版とのちがい）

標準版の手順書 `../../docs/06_assembly.md` のとおり。ちがいは次の 3 つ:

| 標準版 | Lite |
|-------|------|
| ギヤボックスの枠は M3×20 ねじ 4 本で基板・枠・デッキを共締め | **同じ**（電池ボックスはモーターの上のデッキに付ける） |
| スキッド `skid_clip_h40.stl` を (50, 4) の穴 | **`skid_clip_h75.stl`（7.5 mm）を「スキッド」の穴**（真ん中のセンサーの 7 mm 後ろ）に押し込む。ロボットは少し後ろに傾く（2.9°）が正しい |
| タイヤは O リング P-24 | **TPU の印刷タイヤ**を車輪のみぞにはめる（引っぱって伸ばしながら） |
| 電源ランプで電源 ON を確認 | 電源ランプはない。**電池のスイッチを入れて `main.py` が動くと赤 LED が点く** |
