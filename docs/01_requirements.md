# 01. 要件定義 — 子ども向け教材ライントレーサー「Linetracer2」

> 最終更新: 2026-10-05（rev.A1: R13〜R16 を追加、R17 低コスト版 Lite を追加、R18 Lite を XIAO ESP32C6 ＋ LBR-127HLD に）
> この文書は「何を作るか / なぜそう決めたか」を残すためのもの。設計を変えたら必ずここも更新すること。

---

## 1. 目的

- サークルで新規に作る **子ども向け教材** のライントレーサー。
- 子どもが **自分ではんだ付けして組み立て**、**プログラムを書いて走らせる** ところまでを体験できること。
- 教材としての「わかりやすさ」と、走らせたときの「速さ（楽しさ）」を両立する。

## 3. 派生要件（上の要件から決めたこと）

### 3.1 電気

| # | 派生要件 | 理由 |
|---|---------|------|
| D1 | 電池は **3本直列**（アルカリ 4.5V / ニッケル水素 3.6V） | Pico の VSYS 上限 5.5V 以下に収まる最大本数。4本だとアルカリ新品 6.4V で Pico を壊す |
| D2 | モーターは電池直結（VM）、Pico は **ショットキーダイオード経由**で VSYS へ | USB 接続時に USB 5V が電池へ逆流（充電）するのを防ぐ。モーターは USB からは回らない（＝机の上で暴走しない） |
| D3 | モータードライバは **秋月 AE-TC78H653FTG（¥200）** を DIP16 互換のピンヘッダで実装 | TC78H653FTG 本体は QFN16 (3mm角) で子どもには不可能。モジュールなら 2.54mm ピンをはんだ付けするだけ |
| D4 | TC78H653FTG は **スモールモード（LARGE=L）、INモード（MODE=L）** 固定 | 2モーター駆動のため。1ch あたり 2A(DC)/2.5A(10ms) |
| D5 | **STBY を GPIO で制御**する | TC78H653 は過電流検出(ISD)でラッチ停止し、復帰には STBY の L→H か電源再投入が必要（データシート p.9） |
| D6 | モーター電圧は **PWM で平均 3V 程度に制限**（ソフトで上限設定） | FA-130RA-2270 の定格範囲は 1.5〜3.0V。電池 4.5V をそのまま入れると過電流＆ブラシ寿命低下 |
| D7 | ソフトスタート（デューティを急に上げない） | 起動電流で電池電圧が落ちると Pico がリセット & ドライバの ISD が働く |
| D8 | センサーは **6個 + アナログマルチプレクサ（TC4051BP, DIP16）** で ADC 1本に集約 | Pico の外部 ADC は 3本しかない。4051 は ¥15 と安い |
| D9 | センサーの赤外 LED は **トランジスタで ON/OFF** 可能にする | 外乱光（窓からの日光など）キャンセル、消費電流削減 |
| D10 | 電池電圧を ADC で測る（分圧 1/2） | 電池が減っても同じ速さで走れるよう補正する／電池交換の目安 |
| D11 | 子どもが使う UI: **タクトスイッチ×2、LED×2、圧電スピーカ（オプション）** | 「スタート」「モード切替」「状態表示」「音」 |
| D12 | 拡張用に **I2C ヘッダ（0.96" OLED と同じピン順）** と予備アナログ入力 | 発展課題（距離センサ・表示器・マーカーセンサ追加） |

### 3.2 機械

| # | 派生要件 | 理由 |
|---|---------|------|
| M1 | **基板そのものをシャーシにする** | 部品点数とコストを最小化 |
| M2 | 基板は **100 × 100 mm 以内** | JLCPCB 等で最安価格帯（5枚 $2〜） |
| M3 | 後ろ2輪駆動（左右独立）＋前にスキッド1点 | 3点接地は床に必ず全点が接地する（がたつかない） |
| M4 | 基板下面の高さ ≒ 4 mm、センサー面 ≒ 2〜3 mm | LBR-123F は検出距離が短い（数 mm）。センサーを基板の裏に直接付けられる高さにする |
| M5 | 減速は **1段平歯車 (m0.5) 8T→40T = 5:1**、車輪径 約 32 mm | 130モーターは高回転（3V 無負荷 17,400rpm）。この組合せで最高速度は十分（7章）。ピニオンはタミヤ（ミニ四駆用）、平歯車は 3D プリント |
| M6 | ギヤボックス（モーター＋車軸の保持具）は 3D プリント（P1S） | 安い・調整しやすい。柱 2 本に M3×20 を通し、基板・デッキと一緒に締める |
| M7 | 電池ボックスはモーターの上の **3D プリントのデッキに M3 皿ねじ 2 本で固定**（テープは使わない） | 基板面積を電子回路に使う。重心を駆動輪の近くにしてトラクションを稼ぐ。デッキはモーターの押さえも兼ねる |
| M8 | スキッドは**ツメで基板の穴に差し込む**。高さ違い（3.5 / 4.0 / 4.5 mm）を印刷して交換できる | センサーと床の距離を、部品を替えるだけで調整できる。ねじ・ナイロンナットが要らない |
| M9 | ツメにするのは「荷重がかからない所」だけ（スキッド、任意で電池ボックス）。基板・枠・デッキはねじ | PLA のツメは荷重がかかり続けるとゆるむ（クリープ）。基板をつかむツメは枠を平らに印刷できない |

### 3.3 子ども向け（作りやすさ）

| # | 派生要件 |
|---|---------|
| K1 | 部品はすべて足付き（リード）部品。ピッチは 2.54 mm 以上（センサーだけ 1.8 mm、ランドを楕円にして間隔を確保） |
| K2 | 抵抗の値は **100Ω / 1kΩ / 10kΩ の3種類だけ** にする（カラーコード読み取りの混乱を減らす） |
| K3 | シルクに **部品番号と値（例: R1 10k）、極性（+, 赤/黒、ダイオードの帯）** を印刷 |
| K4 | 電池は **XH コネクタ付き電池ボックス**（線のはんだ付け不要・抜き差し可） |
| K5 | 逆接続しても Pico は壊れない（ダイオード）。ただしモータードライバは守れないので、組立手順書で「赤＝＋」の確認を必須にする |
| K6 | ランドは標準より大きめ（1.8〜2.0 mm）で、はんだが乗りやすいようにする |
| K7 | 機械部品の固定は **M3 ねじ（なべ M3×20 ×4、皿 M3×8 ×2、ナット）と 3D プリントのツメ**（スキッド、任意で電池ボックス）。ドライバー 1 本で組み立て・分解できる |

| # | 派生要件 | 理由 |
|---|---------|------|
| S1 | 購入先は 秋月電子通商（店頭・通販）、ホームセンター、模型店・ヨドバシ・Amazon（Amazon.co.jp 販売のタミヤ品）、モノタロウ | どこも T 番号入りの領収書（適格請求書）を出せる → 大学の会計で精算できる |

## 4. やらないこと（スコープ外）

- エンコーダによる速度フィードバック（コスト増。発展課題として I2C/予備ピンで後付け可能にしておく）
- 無線（Pico W / Pico 2 W を挿せばソフトだけで使える）
- 表面実装部品の手はんだ

## 5. コスト目標と結論（詳細は `05_bom.md`）

| 構成 | 合計（1台, 税込目安） |
|------|------------------|
| 全部新品（純正 Pico ¥800 込み、基板 ¥80） | **約 ¥2,370** |
| Pico を講座で再利用する（Pico 以外の部品代） | **約 ¥1,540** |
| 上に加えて、ねじ・O リング・フィラメントをまとめ買い | **約 ¥1,440〜1,500** |

- **純正 Pico だけで ¥800（全体の約 1/3）** あり、全部新品で ¥1,500 以内は無理。
- R14（T 番号のある店だけ）により、以前の案（海外通販の Pico 互換ボード・互換モーター）は使えなくなった。**¥1,500 にするには「Pico を再利用（貸し出し）」がほぼ唯一の方法**。
- 回路・基板はどの方法でも同じものが使える。

## 7. 性能目標（概算）

- 最高速度: 1.5〜2 m/s（ソフトで制限。ハード的には 4 m/s 以上出せるギヤ比）
- 加速度: 3〜4 m/s²（モーター電流 約 1.5 A/個 以内）
- 制御周期: 1 kHz（センサー6個読み + PD 制御）
- 連続走行: アルカリ単3で 30 分以上

計算の詳細は `02_concept.md` の「駆動系の計算」を参照。
