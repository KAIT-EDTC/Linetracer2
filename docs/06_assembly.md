## 2. 電気のチェック（電池を入れる前に！）

テスターの抵抗レンジで:

| 測る所 | 正常 | おかしいとき |
|--------|------|-------------|
| J1 の＋ と − | 数百Ω 以上（コンデンサの充電でだんだん上がる） | 0Ω 近く → どこかショート（ブリッジ）。C1 の向き、U3 のはんだを確認 |
| C2 の＋ と − （VSYS） | 数 kΩ 以上 | Pico の VSYS/GND のブリッジ |
| センサーの足どうし | つながっていない | はんだブリッジ |

目視: Pico の 40 ピン、センサーの 4 ピン、U2 の 16 ピンにブリッジ（隣とつながったはんだ）がないか。

## 3. はじめての電源（USB だけ）

1. 電池ボックスのスイッチは **OFF**。
2. Pico を USB でパソコンにつなぐ → **黄緑の PWR LED が点く**。点かなければ、Pico のヘッダのはんだ、D4 の向きを確認。
3. MicroPython を書き込み、サンプル `01_led_blink.py` → `02_buttons_buzzer.py` → `03_sensor_monitor.py` を順に動かす（`07_firmware.md`）。
4. `03_sensor_monitor.py` で、白い紙の上と黒い線の上で値が変わるか確認（白: 大きい / 黒: 小さい）。変わらないセンサーは向き・はんだを確認。

## 4. 機械の組み立て（ねじだけで固定する）

![exploded](../hardware/mechanical/exploded.png)

全体の重なり（下から）: **基板 → 枠（モーター・ギヤ・車輪入り）→ デッキ（青）→ 電池ボックス**。
M3×20 のねじ 4 本が、基板の裏から「基板・枠・デッキ」をまとめて締める（ナットはデッキの中）。

| ねじ | 数 | どこ |
|------|----|------|
| なべ小ねじ M3×20 | 4 | 基板の裏 → 枠の柱 → デッキのナット |
| 皿小ねじ M3×8 | 2 | 電池ボックスの中 → デッキのナット |
| 皿小ねじ M3×8 ＋ **ナイロンナット** | 1 | スキッド |
| 六角ナット M3 | 6 | デッキの六角の穴（上に 4、下に 2） |

### 4.1 スキッド（前のすべり足）

1. 基板の裏（センサー面）の前中央 `SKID` の穴に、スキッドの**平らな面**を当てる（丸いほうが床側）。
2. スキッドの側から **M3×8 皿ねじ**を差し、表に出たねじの先に **ナイロンナット**を付けて締める。
   - **金属のナットは使わない**（となりのセンサーのはんだに触れてショートする）。
   - センサーの高さを変えたいときは `skid_h35.stl`（3.5 mm、床に近づく）/ `skid_h45.stl`（4.5 mm）に替える。

### 4.2 モーターの準備

1. モーターの端子 2 か所に電線（長さ約 6cm）をはんだ付け。**赤い印のある端子 → 赤い線**。
2. （おすすめ）端子の間に 0.1µF を 1 個はんだ付けすると雑音が減る。
3. **ピニオンギヤ 8T** をモーター軸に押し込む。**ピニオンの外側の面が軸の先端とそろう**所まで（入れすぎない）。万力やペンチで、**モーター本体を押さないように**軸の反対側（後ろの出っぱり）を支えて押す。

### 4.3 ギヤボックス（左右 2 つ作る）

1. **平歯車 40T** を、枠の「外側の壁」と「内側の軸受け」の間に入れる。**出っぱり（ハブ）がモーター側**。
2. **車軸**を枠の外側から穴に入れ、平歯車の穴に押し込みながら、**止まるところまで**差す（平歯車はきつくはまる。壁が平歯車を支えるので位置は自動で決まる）。
3. 車軸の外側の端に**車輪**を押し込む。車輪と枠の丸い出っぱりの間に**はがきを 1 枚はさんで**押し込み、はがきを抜く（すき間 約 0.3 mm）。
4. 車輪のみぞに **O リング**をはめる。
5. **モーター**を枠のゆりかごに入れる: 前の丸い出っぱり（φ6）を壁の丸い穴に先に入れてから、後ろを押し下げてパチッとはめる。ピニオンと平歯車がかみ合う。
6. 車輪を指で回して、引っかかりなく回るか確認。

### 4.4 電池ボックスをデッキにつける

1. デッキ（青い板）の**上の面**の六角の穴 4 つに、ナットを 1 個ずつ入れる。
2. デッキの**下の面**のまん中の六角の穴 2 つにナットを入れ、指で押さえておく。
3. 電池ボックス（**スイッチが左・線が右**）をデッキに載せ、ボックスの中の 2 つの皿穴から **M3×8 皿ねじ**でデッキの下のナットに締める。
   → これで上の 4 つのナットは電池ボックスの下に閉じこめられ、落ちない。

### 4.5 基板に取り付ける

1. 左右のギヤボックスを、基板の表のシルク（`MOTOR L` / `MOTOR R` の四角）に合わせて置く。
2. **基板の裏から M3×20 なべねじ**を 4 本、基板の穴 → 枠の柱の穴に通す（車輪とスキッドで立たせておけば、ねじは下に落ちない）。
3. モーターの線を `M1 LEFT`（左）/ `M2 RIGHT`（右）の穴へ。**まず後ろの小さい穴（引っぱり防止）に上から通し、裏から前の大きい穴に戻して表ではんだ付け**。赤い線を `+` に。
   - **デッキを付ける前に**はんだ付けすること（付けた後はこてが届かない）。
4. **電池を抜いた**電池ボックス＋デッキを、柱の上に載せる（4 本のねじの先がデッキの穴に入る）。
5. 全体を手で押さえたまま**ひっくり返し**（電池ボックスが下）、上を向いた基板の裏から 4 本のねじをドライバーで締める。ナットはデッキの中で回らないので、ねじを回すだけでよい。
6. 元に戻して電池を入れ、電池ボックスのプラグを J1 に差す。余った電池の線は電池ボックスの横に沿わせる。

> 分解するときは逆の順（ねじ 4 本を外すと、電池ボックス＋デッキがまとめて外れる）。

## 5. 走らせる前の確認

1. **車輪を浮かせて**（箱の上などに乗せて）`04_motor_test.py` を実行 → 「前進」で両輪が前に回るか確認。逆なら `linetracer.py` の `LEFT_INVERT` / `RIGHT_INVERT` を変える（またはモーターの線を入れ替える）。
2. `main.py` を書き込み、コースの線の上に置いて START → 自動キャリブレーション（その場で左右に回る）→ もう一度 START で走る。
3. うまく走らないときは `07_firmware.md` の「調整のしかた」。

## 6. よくあるトラブル

| 症状 | 原因と対策 |
|------|----------|
| USB でつないでも PWR LED が点かない | Pico のはんだ不良。3V3（36番ピン）と GND の間の電圧を確認 |
| 電池を入れると PWR が点くがモーターが回らない | 電池ボックスのスイッチ、J1 の向き（赤＝＋）、U3 のはんだ。`04_motor_test.py` の電池電圧表示が 3V 以下なら電池切れ |
| モーターが一瞬回ってすぐ止まる | ドライバの過電流保護（ISD）。ライブラリが 0.1 秒ごとに自動復帰するが、何度も止まるならギヤの噛みすぎ・車輪の擦れ（重い）を確認 |
| ギヤがガリガリ鳴る／重い | 平歯車の印刷が太い。`linetracer2_mech.scad` の `GEAR_BACKLASH` を 0.15 にして印刷し直す（`hardware/mechanical/README.md`） |
| 車輪が空回りする | 車輪または平歯車の穴がゆるい。印刷し直す（穴を 0.05 mm 小さく）。テープ・接着剤では直さない |
| 走り出すと Pico がリセットする | 電池が弱い。ニッケル水素電池を使う、速度レベルを下げる |
| センサーの値が白黒で変わらない | センサーの向き（裏から差したか、ピン1の向き）、はんだ。床とセンサーの距離（2〜3mm）も確認。スキッドの高さを替える（4.1） |
| ある場所だけ線を外れる | 窓からの光、コースのつなぎ目。外乱光キャンセル（`ambient_cancel = True`）を使う |
