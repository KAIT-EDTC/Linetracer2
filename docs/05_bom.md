## 0. 買い方のルール（サークルの方針）

| ルール | 理由・やり方 |
|-------|------------|
| **実店舗で売っている物、または T 番号（適格請求書発行事業者の登録番号）のある通販で買える物だけ使う** | 大学の会計で精算できるように、**適格請求書（T 番号入りの領収書・請求書）** を必ずもらう |
| 通販は **秋月電子通商**（店頭・通販）、**Amazon**（下の注意）、モノタロウ、ヨドバシなど | どこも T 番号入りの領収書を出せる。T 番号は [国税庁 適格請求書発行事業者公表サイト](https://www.invoice-kohyo.nta.go.jp/) で確認できる |
| Amazon は **「Amazon.co.jp が販売・発送」または出品者が適格請求書発行事業者** のものだけ | マーケットプレイスの無名品は T 番号が無いことがあり、在庫も安定しない。**ブランド品（タミヤ・光など）を選ぶ** |
| 海外通販（AliExpress 等）・ノーブランド品は使わない | 精算できない／同じ物が二度と買えないことがある |
| 3D プリント部品はサークルの **Bambu Lab P1S** で作る | 材料はフィラメントだけ（ヨドバシ・Amazon で買える） |

> 例外: **基板（PCB）は特注品**なので店では売っていない（[§4](#4-基板の発注)）。

## 3. 合計と ¥1,500 について

| 構成（1 台） | 合計 | 内訳 |
|-------------|------|------|
| **A. 全部新品（純正 Pico 込み、基板 ¥80、ブザー別）** | **約 ¥2,370** | 電子 ¥1,461 ＋ 基板 ¥80 ＋ 機械 ≒¥832 |
| **B. Pico を講座で再利用（貸し出し）する** | **約 ¥1,540** | A から Pico ＋ ピンヘッダ（¥835）を除く |
| B ＋ まとめ買いの工夫 | 約 ¥1,440〜1,500 | ねじ・ナットを徳用袋、O リング・フィラメントを安い銘柄で（−¥100 程度）。ツメ版デッキならさらに −¥30 |

- **純正 Pico だけで ¥800（全体の約 1/3）**。以前の案（海外通販の Pico 互換ボード・互換モーター）は「T 番号のある店だけ」のルールで使えなくなったので、**¥1,500 に近づけるには「Pico を再利用」が現実的な唯一の方法**。
- 価格が大きいもの: Pico ¥800、センサー 6 個 ¥240、モーター 2 個 ¥300、ドライバ ¥200。センサーを 4 個に減らすと −¥80 だが、性能（位置の分解能）が落ちるのでおすすめしない。
- 部品は授業の台数ぶんまとめて買うと、抵抗・コンデンサ・ねじの袋の余りが減る（下の §5）。
- **Lite**（`../lite/README.md`）: rev.L3 は XIAO ESP32C6（ピンヘッダ）・LBR-127HLD 3 個・ボタン 1 個・LED 1 個・ブザー（ボタンと同じピン）・TPU タイヤ・Lite 用ボールキャスターで **約 ¥2,530（+¥160）**。部品は減るが XIAO（¥1,100）とセンサー（¥80）が高いので標準版より高い。基板側をピンソケットにすれば XIAO を回収して使い回せる。前の版（rev.L2 約 ¥2,480、Pico 版の rev.L1 約 ¥2,060）は git の履歴にある。

## 4. 基板の発注

- 基板は特注品なので**店頭販売は無い**。Gerber: `hardware/Linetracer2_rev.A1_gerber.zip`、仕様と手順は `04_pcb.md` §5。
- **JLCPCB（中国）** が最安（30 枚で 1 枚 ¥40〜100 程度＋送料）だが海外の業者。**大学の会計で精算できるか事前に確認**すること（日本の T 番号入り請求書は出ない前提で考える）。
- 精算の都合で国内業者が必要なら、P板.com などの国内の基板製造サービスに同じ Gerber で見積りを取る（1 枚あたりは JLCPCB より高い）。
